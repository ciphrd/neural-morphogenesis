ID / Membrane Stickiness Sandbox

Ports trainer/backend/physics.py's relax() math exactly (Jacobi surface tension + collision, same constants), run continuously frame-over-frame instead of converge-and-stop, so pairwise tension can be watched directly and every tweak takes effect live. Each node's 3-dim id vector is shown as RGB — tension between two nodes in range is scaled by the cosine similarity of their ids, clipped to [0, 1] ("homophilic adhesion"): matching ids pull at full strength, orthogonal/opposed ids feel nothing, never repulsion.

A zero id vector has no direction — cosine similarity against it is undefined. The real code's fallback (norms < 1e-9 → norm = 1) makes a zero vector's "unit" form [0,0,0], so its dot product with anything, including another zero vector, is 0 → clipped compatibility 0. Two "matching" zero-id nodes get no pull, same as fully opposed ids. Try experiment 5.
