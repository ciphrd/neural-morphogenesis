Repulsion Field Sandbox

Cheap O(N) stand-in for pairwise repulsion: every agent splats a Gaussian blob onto a low-res density field, a finite-difference gradient is computed on that field once (O(resolution²), not O(N²)), and each agent is nudged down its own negative gradient — away from wherever density is locally high. No agent ever looks at another agent directly.

Initial layout

"Collapsed" starts every agent within half a pixel of the exact same point — the failure case this is meant to fix. A field's gradient is exactly zero at its own peak, so agents need *some* asymmetry to ever start separating; the tiny built-in jitter provides just enough for the (self-reinforcing, amplifying) repulsion to take it from there.
