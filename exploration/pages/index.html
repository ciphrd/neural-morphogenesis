Exploration

  • gradient-field

    Interactive sandbox: drop nodes with a 3-channel value, see the resulting field and its analytic gradient — same math as backend/substrate.py, 3 channels shown as RGB.

  • id-adhesion

    Interactive sandbox: a faithful port of backend/physics.py's relax() (Jacobi surface tension + collision), with id-modulated adhesion shown live. Five built-in experiments (cell sorting, membrane boundary, chain fragmentation, zero-id edge case) plus a sorting-affinity metric and per-node tension-link inspector.

  • distance-sandbox

    Interactive sandbox: click to place nodes (held together by tension + collision physics), load a real target from the trainer backend or fall back to a built-in circle, and drag it around — the Chamfer distance (the actual training fitness metric) updates live, with optional nearest-neighbor pair lines showing what's driving the number.

  • mpm-distance-compare

    Side-by-side comparison of mpm-training's two fitness metrics — distance.py's Chamfer distance vs. raster.py's Gaussian-splat raster distance (coverage + outside-shape penalty) — against the same particle placement. Pick a target (circle/line/donut), apply a preset distribution (jittered match, ring, cluster, scatter, offset, single point) or click particles by hand, and watch both numbers respond, with a live preview of the actual raster each metric scores against.

  • repulsion-field

    Live particle sandbox for a cheap O(N) alternative to pairwise repulsion: agents splat a Gaussian blob onto a low-res density field, a finite-difference gradient is computed on that field once, and each agent moves down its own negative gradient — away from local density, without ever looking at another agent directly. Built to test whether this breaks envnca's agent-collapse failure mode (all agents converging onto a single point, a stable fixed point that gradient descent alone can't escape).
